## 执行记录

**执行人**：
**日期**：
**AstrBot 版本**：4.23.3
**插件版本**：v0.2.1

### 测试 1：非流式 × compat 关

- 配置：`streaming_compat_enabled: false`
- 触发：向 LLM 发送"介绍一下量子计算"
- 观察：
  - [ ] 回复被分为多段
  - [ ] 首段立即发送
  - [ ] 剩余段延迟补发（观察到明显间隔）
  - [ ] 日志无"补丁已启用"
- 结论：✅ / ❌

### 测试 2：非流式 × compat 开

- 配置：`streaming_compat_enabled: true`，触发同上
- 观察：
  - [ ] 分段与补发行为同测试 1
  - [ ] 无流式日志噪音
- 结论：✅ / ❌

### 测试 3：流式 × compat 关

- 配置：开启 AstrBot 流式输出，`streaming_compat_enabled: false`
- 观察：
  - [ ] 输出为原始流式（无分段干预）
  - [ ] 日志无"补丁已启用"
- 结论：✅ / ❌

### 测试 4：流式 × compat 开

- 配置：流式 + `streaming_compat_enabled: true`
- 观察：
  - [ ] 按标点/长度实时拆成多条可见消息
  - [ ] 日志显示"智能分段已接管流式输出"（info）与"补丁已启用"
- 结论：✅ / ❌

### 测试 5：流式 × compat 开 → 关闭插件

- 操作：流式正常时关闭/卸载插件
- 观察：
  - [ ] 补丁被恢复，流式还原原样
  - [ ] 无异常堆栈
- 结论：✅ / ❌

### 测试 6：流式 × compat 开 → 热重载

- 操作：插件热重载（reload）
- 观察：
  - [ ] 无重复包装（新补丁安装先恢复旧补丁）
  - [ ] 日志无"旧补丁残留"WARNING
- 结论：✅ / ❌

### 测试 7：分段模型超时

- 配置：`timeout_seconds: 0.1`
- 观察：
  - [ ] 超时后本地规则兜底分段
  - [ ] 原回复内容不丢
- 结论：✅ / ❌

### 测试 8：发送中断

- 操作：补发期间断开网络
- 观察：
  - [ ] 剩余补发停止，无异常堆栈
  - [ ] 日志出现"补发发送失败，已停止剩余补发"（warning）
- 结论：✅ / ❌

## 异常场景补充测试

- [ ] LLM 返回纯 action-only 文本（如"（思考中）"）：不应被二次拆分
- [ ] LLM 返回包含 thinking 标签的内容：标签应被剥离
- [ ] 配置 max_segments=2，LLM 返回 5 段：应合并为 2 段（首段 + 尾 4 段合并）
